# 🤝 Contributing

Thank you for your interest in contributing to the **Hospital Emergency Room Dashboard** project!

## How to Contribute

1. **Fork** this repository
2. **Create** a feature branch (`git checkout -b feature/your-feature`)
3. **Commit** your changes (`git commit -m "Add: your feature description"`)
4. **Push** to the branch (`git push origin feature/your-feature`)
5. **Open** a Pull Request

## Guidelines

- Follow the existing project structure
- Document any new DAX measures in the `Scripts/DAX/` folder
- Add screenshots for any dashboard changes to `Screenshots/`
- Update `CHANGELOG.md` with your changes

## Questions?

Feel free to open an issue or reach out directly.
